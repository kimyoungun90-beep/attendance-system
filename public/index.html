대체 휴무 부여

대체휴무는 엑셀 업로드가 아니라 웹에서 경로·월·사용 가능 기간을 지정해 부여합니다.

부여 내역

저장된 부여값은 대체 사용자 시트와 월 마감 누적 파일에 반영됩니다.

경로발생 월1인당사용 기간비고
등록된 대체휴무 부여 내역이 없습니다.

연차 관리

연차는 승인·반려 양식에서 승인된 건만 근태에 반영하고, 전월 연차 마감 파일 디자인 기준으로 연차 엑셀을 생성합니다.

현재 대상 월에 등록된 연차 누적 DB 없음

연차 출력 기준

근태 엑셀에는 승인 연차·반차만 입력되고, 연차 엑셀에는 사용자·누적관리·촉진 관리가 따로 생성됩니다.

반려·취소·철회 건은 정상 연차로 보지 않습니다.

근무계획에는 연차인데 승인 양식에 없는 건은 연차 확인 대상으로 분리합니다.

전월 마감 파일은 연차 잔여와 촉진 상태를 이어받는 기준 파일입니다.

원본 업로드

출근은 제모스 근태기록 기준, 휴무·공가·휴가·경조는 매니저별 파일 기준으로 반영합니다.

현재 대상 월에 등록된 인력 DB 없음

매니저별 증빙 파일 등록

전자랜드 매니저별 파일에서 휴무·공가·휴가·경조·대체휴무 등 확정값을 가져옵니다.

등록된 매니저 수정본 없음

출근증빙 처리 완료본

증빙 확인된 출근·반차 값은 웹에서 바로 저장할 수 있고, 완료본 엑셀 업로드도 보조로 사용할 수 있습니다.

웹 출근증빙 확인

분석 후 확인 대상을 선택하면 현재 경로·월 기준으로 저장되고, 재분석 시 근태 시트에 반영됩니다.

이름사번발생일확인 구분처리값메모
분석 후 출근증빙 대상이 표시됩니다.

월 마감 누적 관리

중간 저장은 사용하지 않습니다. 월 마감 누적 파일만 별도로 내려받아 다음 달 연차·대체 기준으로 씁니다.

근태 엑셀: 근태 시트, 휴무 초과자, 대체 사용자, 연차 사용자, 연차 누적관리, 연차 촉진 관리, 그 외 사용자, 근태 확인 인원, 출근 기록

연차 엑셀: 전월 연차 마감 파일 디자인 기준으로 별도 생성
