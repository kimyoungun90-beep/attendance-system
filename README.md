# 근태 관리 시스템 clean v5

기존 패치 체인을 다시 이어붙이지 않고, Cloudflare Pages + D1 저장 연결만 유지한 클린 기준본입니다.

## 핵심 기준

- 근무계획은 선택 입력입니다. 없어도 매니저 파일, 제모스 출근 기록, 연차 기록, 인력 DB 기준으로 엑셀을 생성합니다.
- 출근은 제모스 출근 기록을 우선 기준으로 봅니다. 실제 출근시간이 있으면 빨간색 경고를 적용하지 않습니다.
- 휴무, 공가, 휴가, 경조, 대체휴무, 보상휴가는 매니저별 증빙 파일 기준으로 근태에 반영합니다.
- 대체휴무는 엑셀 업로드가 아니라 웹에서 경로, 발생 월, 1인당 부여 일수, 사용 가능 기간을 직접 저장합니다.
- 출근증빙은 웹에서 처리값을 저장할 수 있고, 처리 완료본 엑셀 업로드는 보조 수단으로 남깁니다.
- 인력 매칭 DB와 연차 누적 DB는 현재 경로와 대상 월 기준으로 따로 저장하고 불러옵니다.
- 중간 저장 시스템은 사용하지 않습니다. 월 마감 누적 파일만 별도로 생성합니다.
- 연차는 승인·반려 양식에서 승인된 건만 정상 연차·반차로 인정합니다.
- 전월 연차 마감 파일을 업로드하면 연차 잔여, 촉진 상태, 월별 연차 사용량을 다음 달 연차 엑셀로 이어받습니다.
- 암호가 걸린 엑셀은 브라우저에서 직접 읽을 수 없으므로 암호 해제 후 업로드합니다.

## D1

새 테이블 `attendance_clean_store` 하나만 사용합니다. 저장 키는 경로와 대상 월을 포함합니다.


## Clean v6 연차 누적/촉진 보강
- 연차신청현황 승인건을 월별 누적 사용량에 합산
- 전월 마감본의 잔여연차 및 1·2차 촉진 상태 승계
- 생성된 마감본을 다음 달 다시 업로드해도 동적 헤더로 재인식
- 연차 엑셀에 연차사용 누적 및 월마감 누적관리 시트 포함

## Clean v7 원본 연차촉진 템플릿 적용
- 비밀번호 `z2026`으로 복호화한 실제 전자랜드 6월 마감본을 연차 엑셀 원본 템플릿으로 포함했습니다.
- 원본 16개 시트, 숨김 열, 촉진 문서, 인쇄 설정을 유지하며 사람별 데이터만 교체합니다.
- 전월 마감본 업로드 시 현재 월 시트를 숨김 전월 시트로 승계하고 대상 월 시트를 생성합니다.
- 재직 1년 이상/미만, 당월 승인 연차·반차, 잔여연차, 1·2차 촉진 상태, 연차 소진일을 누적 반영합니다.
- 숨김 연차사용 원장에 당월 사용량을 월별로 합산합니다.

## 회사 보안 환경용 코드 전용 배포본
- 이 ZIP에는 회사 보안 문서로 판정될 수 있는 `annual-template.xlsx` 원본이 포함되어 있지 않습니다.
- 연차 엑셀 생성 전, 회사 보안 절차에 따라 승인·복호화한 전월 연차촉진 마감본을 웹앱의 `전월 연차 마감본` 항목에 업로드해야 합니다.
- 파일명 변경이나 압축 재포장으로 회사 보안 정책을 우회하지 마십시오.

## 2026-08-05 업로드 파일 자동 저장 수정

- 연차신청현황 엑셀, 근무계획 엑셀, 제모스 근태기록 엑셀을 현재 경로/대상 월별로 IndexedDB에 자동 저장합니다.
- 매니저별 증빙 파일도 매니저/경로/대상 월별로 자동 저장합니다.
- 페이지 새로고침 또는 재접속 시 저장 파일을 자동 복원합니다.
- 매니저 카드마다 `개별 제거` 버튼을 추가했습니다.
- `전체 제거`는 현재 경로/대상 월의 매니저 증빙 파일만 모두 삭제합니다.
- 대시보드 `초기화`는 분석 결과와 임시 전월/증빙 파일만 초기화하며, 자동 저장된 원본 파일은 유지합니다.
- 브라우저의 사이트 데이터 삭제, 시크릿 모드 종료, 다른 브라우저/PC 사용 시에는 저장 파일이 공유되지 않습니다.

- 근무계획, 근태기록, 연차현황, 전월 연차촉진 마감본, 매니저별 증빙 파일을 IndexedDB에 월·경로별 자동 저장/복원합니다.
- 매니저별 증빙 파일 개별 제거 기능을 유지합니다.
