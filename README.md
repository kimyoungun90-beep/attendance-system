# 근태 관리 시스템 clean v3

기존 v71~v76 패치 체인을 이어붙이지 않고 새로 만든 클린 기준본입니다.

## 핵심 기준

- 엑셀 템플릿 파일에 의존하지 않고 브라우저에서 새 워크북을 생성합니다.
- 대상 월의 연도와 월은 항상 `targetMonth`에서만 파싱합니다.
- 실제 출근시간이 있으면 계획이나 관리자 수정과 무관하게 빨간색 경고를 적용하지 않습니다.
- 관리자 수정본은 휴무, 연차, 오전반차, 오후반차, 출산휴가, 육아휴직, 공가, 경조, 대체휴무, 보상휴가만 반영합니다.
- 관리자 수정본의 출근, 근무, 시간값은 자동 반영하지 않고 출근증빙 대상으로 유지합니다.
- 출근증빙·휴무확인에서 O 처리한 항목은 재생성 시 빨간색 경고를 다시 붙이지 않습니다.
- 휴무 초과자는 근태 시트 기준으로 기본 휴무 초과자만 표시합니다.
- 전월 연차 마감 파일을 업로드하면 연차 잔여, 촉진 상태, 월별 연차 사용량을 다음 달 연차 엑셀로 이어받습니다.
- 누적 파일에 암호가 걸려 있으면 브라우저에서 직접 읽을 수 없으므로 암호 해제 후 업로드합니다.

## 생성 시트

### 근태 엑셀

1. 근태 시트
2. 휴무 초과자
3. 대체ㆍ보상
4. 그 외 사용자
5. 근태 확인 인원
6. 출근 기록

### 연차 엑셀

1. 상담사(재직 1년 이상)_월
2. 상담사(재직 1년 미만)_월
3. 연차 사용자
4. 연차 누적관리
5. 연차 촉진 관리

### 월 마감 누적 파일

1. 월마감 누적관리
2. 당해연도 연차사용
3. 대체 사용 누적

## D1

새 테이블 `attendance_clean_store` 하나만 사용합니다. 기존 v61~v76 D1 테이블과 섞이지 않습니다.
